# Notebooks

Notebooks are for exploration and figure drafting. They are never the source of a reported result.

- **Names:** `NN_initials_topic.ipynb`, e.g. `01_mti_mr_first_look.ipynb`.
- **Inputs:** read from `results/` or `data/processed/` only.
- **Outputs:** never write into `data/`. A figure that goes into the paper is regenerated by a pipeline rule.
- **Before committing:** clear outputs (`jupyter nbconvert --clear-output --inplace <file>`, or install `nbstripout`).
- **Promotion:** once code in a notebook is reused, move it into `src/autoimmune_mo/` with a test.
