# Manuscript

Drafted in Markdown, one file per section, so text, figures and tables stay next to the code
that produces them. This folder is excluded from the public docs site.

| File | Section |
| --- | --- |
| `00_title_abstract.md` | Title, authors, structured abstract |
| `01_introduction.md` | Introduction |
| `02_methods.md` | Methods (cite `docs/methods/` pages as you go) |
| `03_results.md` | Results |
| `04_discussion.md` | Discussion |
| `references.bib` | BibTeX references |
| `figures/`, `tables/` | Final figures and tables, copied from `results/` by a pipeline rule |

## Rules

- Every number in the text comes from a file in `results/`. Note the file in a comment: `<!-- results/demo/model_summary.tsv -->`.
- Figures are regenerated by the pipeline, never edited by hand.
- Reporting checklists: TRIPOD+AI (prediction models), STROBE (cohort), STREGA/STROBE-MR (genetics, MR).

## Building a Word or PDF draft

```bash
pandoc docs/manuscript/0*.md --citeproc --bibliography docs/manuscript/references.bib \
  -o docs/manuscript/draft.docx
```

To draft privately before publication, move this folder into the private grant repository
(see `ROADMAP.md`) and add `docs/manuscript/` to `.gitignore`.
